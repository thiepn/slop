# SLOPOCALYPSE — The Artificial Internet

A fictional, deliberately AI-sloppy, interconnected 44-page web universe (Phase 10).

## Publishing

This repository is being prepared for the full static site. The GitHub Pages workflow requires all **44 HTML pages** plus their CSS and JavaScript assets in the **repository root**; a ZIP file by itself is not a deployable site.

1. Add all extracted files from `SLOPOCALYPSE_GitHub_Pages_Ready.zip` to the repository root, replacing this README if desired.
2. In **Settings → Pages → Build and deployment**, set **Source** to **GitHub Actions**.
3. Check the workflow `Deploy SLOPOCALYPSE to GitHub Pages` and verify the live URL: https://thiepn.github.io/slop/

The workflow intentionally rejects incomplete uploads and must not be considered a successful site deployment until the complete source is committed and GitHub Pages succeeds.

## Data caveat

Progress is saved using browser-local storage, isolated by origin. Export your progress from the localhost site, then import it on the Pages origin to transfer saved state.

All accounts, people, finance, AI, and media interactions are fictional simulations; there are no real backends, financial services, or AI APIs.
