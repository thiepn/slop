# GitHub Pages deployment checklist

- [ ] Repository `thiepn/slop` exists and contains this project at its root.
- [ ] Default branch is `main`.
- [ ] Repository Settings → Pages → Source = `GitHub Actions`.
- [ ] `Deploy SLOPOCALYPSE to GitHub Pages` workflow completed successfully.
- [ ] `https://thiepn.github.io/slop/` loads.
- [ ] Representative internal pages and navigation load.
- [ ] Saved progress is separately backed up when changing origin.

This static distribution is a parody. All user content is saved locally to the browser, not synced with GitHub.
